- 호출별 승인의 사용 기간(마이그레이션 `033_call_approval_window`). 승인할 때 1회(기본, 첫 일치 호출에서 소비)·10분·30분 중 고른다. 10분·30분 승인은 소비되지 않고 승인 시각부터 그 시간 동안 같은 결속(주체·서버·도구·인자 지문·계약·대상)의 호출에 되풀이해 쓰이며, 쓸 때마다 추가만 되는 `call_approval_uses`에 호출 식별자별 한 행이 남는다. 승인 행은 쓸 때 바뀌지 않으므로 여러 복제본이 동시에 써도 서로 막지 않고 상태 세대도 오르지 않으며, 기간이 끝나거나 취소되면 바로 맞지 않는다. 기간은 대기에서 승인으로 넘어갈 때만 정해지고 이후 바뀌지 않으며 상태 전이·동결 규칙은 그대로이다. 콘솔 호출별 승인 화면의 승인 폼에 1회·10분·30분 선택이 생기고 목록에 사용 기간·남은 시간·사용 횟수가 보인다. `call-approval approve --for 10m|30m`, HTTP API `window_minutes`.
