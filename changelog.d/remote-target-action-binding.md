- 원격 서버 호출의 대상·행위 결속을 더했다. 승인된 배포 계약의 URL 호스트·도구 이름으로 서버의 프로필(`github`: `owner/repo`와 `method`, `n8n`: 인스턴스·워크플로 ID와 실행 여부)을 자동으로 고르고(`MINT_TARGET_PROFILES`는 덮어쓰기·`none`용), 선택 결과를 판정 사건(`target_profile`·`target_profile_source`)과 `check`에 보인다. 프로필이 정해진 서버는 호출 인자에서 대상과 행위를 구조적으로 뽑고(빠진 인자에는 서버의 실제 기본값을 적용), 변경·실행 호출에는 그 대상·행위에 묶인 호출별 승인을 요구한다. 승인 행에 `target`·`action`이 기록되고 매칭과 소비가 모두 완전 일치를 본다. 프로필에 없는 도구나 대상을 정할 수 없는 변경·실행 호출은 `CALL_APPROVAL_REQUIRED`로 차단한다. 판정 사건에 `bound_target`·`bound_action`과 레지스트리가 아는 원격 자격 주체 `resolved_credential_ref`를 남긴다. 프로필이 없는 서버의 동작은 바뀌지 않는다(마이그레이션 `022_approval_target_binding`, 플러그인 역할에 배포 계약의 URL·허용 도구 읽기 권한을 더한다).
