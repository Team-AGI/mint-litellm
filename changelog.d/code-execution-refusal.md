- LiteLLM 샌드박스 코드 실행 경로를 막는다. 스킬 훅(`container.skills`)과 코드 인터프리터 가로채기는 모델이 만든 코드를 Docker 샌드박스에서 실행하며 MCP 훅을 지나지 않으므로, `pre_call`에서 `container`, `code_interpreter`·`code_execution*` 도구, `litellm_code_execution` 도구와 그 활성 표지를 `MINT-CODE-EXECUTION-FORBIDDEN`으로 막는다. `MINT_ALLOW_CODE_EXECUTION=true`로만 허용하고, `code_interpreter_interception`이 켜진 구성은 허용 없이는 자가 점검이 실패한다(공식 이미지에 늘 있는 llm-sandbox 설치만으로는 기동을 막지 않는다).
