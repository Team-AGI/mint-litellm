- 단말 설치 묶음(Linux, Claude Code): 직원 화면 「단말 설치」에서 사용자 본인의 키를 새로 발급해 담은 묶음(`mint-kit.tar.gz`)을 내려받는다. 묶음의 `install.sh`를 실행하면 사람이 설정 파일을 만지지 않고도 관리형 설정(호출 전·후 훅, 실패 시 차단, 관리형 훅만 허용), 승인된 로컬 서버만 담은 관리형 MCP 목록, 사용자 키가 설치된다. 관리자 권한이 없으면 사용자 수준으로 설치하고 MINT에는 「관리되지 않음」으로 보고된다. 서버는 묶음이 설치하는 실행기를 거쳐서만 시작되며, 실행 파일·스크립트의 해시가 승인된 실행 계약과 다르면 시작되지 않는다. 호출 뒤 훅이 판정 참조를 `POST /mint/v1/result`로 돌려 결과 보고(성공·오류·알 수 없음)를 남긴다. 설치 상태는 `POST /mint/v1/endpoint/report`로 보고되어 `mint.endpoint_installs`(마이그레이션 `020_endpoint_installs`)에 남고 관리자 콘솔 「단말 설치」와 `GET /api/v1/endpoint/installs`에 보인다. 직원 화면에서 다시 내려받으면 이전 키가 지워지고 「연결 해제」로 키를 지울 수 있으며, 설치 묶음의 `install.sh uninstall`이 설정과 파일을 설치 전으로 되돌린다. 키 발급은 `MINT_KIT_ISSUER_KEY`(`/key/generate`·`/key/delete`만 열린 키, `./mint.sh up`·`upgrade`가 없으면 만들어 비밀 폴더에 두고 콘솔에 넘긴다)로 하고, 키에 걸린 팀이 설치 화면에 보이며, 발급하는 키는 훅 경로 셋만 부를 수 있다.
