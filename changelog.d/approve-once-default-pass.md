- 도입 승인은 관리자 한 번으로 끝난다: 직무 분리는 설정(`MINT_REQUIRE_DISTINCT_APPROVER`, 기본 끔, admin 제외)으로만 켜고, 도구 후보·위험 등급·검사 통과·증빙 없이도 승인하며(검사 실패도 자동 거절하지 않고 결정 대기), 기한은 명시할 때만 두고, 승인한 서버의 새 도구까지 기본 허용하며 호출별 승인(R2)은 관리자가 지정한 도구에만 걸고, 서버·도구·사용자·행위(`action:<유형>`) 단위 차단과 해제를 즉시 반영하고, 이미 승인된 서버를 다른 직원이 신청하면 검사 없이 이용 범위만 더한다.
