- 단말 설치 묶음의 주기 보고와 키 만료(POL-D-04·POL-E-06, 마이그레이션 `030_endpoint_key_expiry`: `endpoint_installs.expires_at`·`ttl_days`). 설치한 묶음이 사용자 systemd 타이머(Linux)·예약 작업(Windows)으로 6시간마다(최대 30분 무작위 지연) 같은 설치 보고를 보내고, 서버 실행기가 시작될 때도 보낸다(1시간에 한 번까지). 보고가 `MINT_ENDPOINT_SILENT_HOURS`(기본 24)시간 넘게 끊긴 설치는 경보 `endpoint_silent`(중간)를 열고 보고가 다시 오면 닫으며, 제거된 설치는 제외한다. 새로 발급하는 키는 `MINT_ENDPOINT_KEY_DAYS`(기본 90)일 뒤 만료되고, 만료된 키의 보고는 403으로 거부한다. 만료 14일 안에 들어온 보고는 같은 키의 만료 시각을 유효 기간만큼 늘리며(응답 `renewed`) 만료 7일 안인데 갱신되지 못한 키는 경보 `endpoint_key_expiring`을 연다. 이미 발급된 키는 마이그레이션 시점부터 90일 뒤에 만료되므로 이전 묶음은 다시 설치해야 한다(`docs/업그레이드.md`). 웹훅 안내 문구는 19종이 되었다.
