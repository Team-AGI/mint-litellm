- 단말 프로세스·자동 시작 점검(POL-D-04)과 선언 파일 접근(POL-I-08)을 집계에 넣었다(둘 다 부분). 설치 묶음의 설치·제거 보고가 묶음 실행기(`mint_agent.py run`)로 뜬 프로세스와 자동 시작 항목(Linux: 사용자 systemd 단위·자동 시작 파일·`@reboot` 크론, Windows: Run 키·예약 작업·시작 프로그램 폴더)을 읽기만 해서 함께 보내고(마이그레이션 `028_endpoint_inventory`: `endpoint_installs.processes`·`autostart`), 설치 보고를 보는 작업이 승인 상태가 아니거나 레지스트리에 없는 서버가 가리켜지면 경보 `endpoint_stale_process`·`endpoint_stale_autostart`를 열고 사라지면 닫는다(제거 보고도 본다). 실행 계약에 선언 파일 접근 `file_access`(절대 경로와 읽기 또는 읽기·쓰기)를 더했다. 비어 있으면 계약 해시가 이전과 같고, 선언하면 해시에 들어가 바뀔 때 재승인이 필요하다. `server register-local`에 `--read`·`--read-write`(반복 가능)를 더했으며, 경로 추가나 읽기에서 읽기·쓰기로의 변경은 계약 변경 비교의 파일 접근 확대로 본다. 서버 상세에 「파일 접근」 표를 보인다. 프로세스·자동 시작 목록은 단말의 주장이고 선언은 실제 접근을 막지 않는다.
