- 단말 설치 묶음이 Codex CLI와 Windows를 지원한다. 직원 화면 「단말 설치」에서 운영체제(Linux·Windows)와 도구(Claude Code·Codex·둘 다)를 골라 내려받는다(Windows는 `mint-kit.zip`, `install.cmd`로 설치·`install.cmd uninstall`로 제거). Codex는 관리형이면 관리자 요구 파일(`requirements.toml`: 승인된 서버 외 차단, 관리형 훅만 허용, 호출 전·후 훅)을, 사용자 수준이면 `config.toml`의 표식 구간을 쓴다. 승인된 서버가 없어도 서버 표는 항상 두어 Codex가 서버를 제한하지 않는 상태가 되지 않게 한다. Codex에는 실패 호출 훅이 없어 보고되지 않은 호출은 결과 미확인으로 남는다. Windows는 Program Files·ProgramData의 관리형 경로에 설치하며(모든 사용자용으로 설치한 Python이 필요하다), 관리자 확인을 거절하면 사용자 수준으로 설치해 「관리되지 않음」으로 보고된다. 실행 계약의 경로에 Windows 절대 경로(`C:\...`)를 받는다. `--dry-run`은 임시 폴더에 설치해 쓸 파일만 보이고 실제 설정은 바꾸지 않는다.
