- 사건 원장 월 분할과 선택적 보관(마이그레이션 `034_events_partition`). `mint.events`가 `inserted_at`(UTC) 월 범위 분할 표가 된다. 모든 행·색인·트리거(추가 전용·봉인·비우기 금지·플러그인 종류 제한)·권한은 그대로 옮기고, 분할 표가 가질 수 없는 유일 제약(`event_id`·`(instance_id, source_key)`·`(instance_id, seal_seq)`)은 키 표 `mint.event_keys`가 같은 보장으로 맡는다(중복 삽입 거부, 조용한 건너뛰기는 `mint.claim_event_key`를 같은 문장에서 부른다). 기본 분할이 있어 삽입은 실패하지 않으며, 기본 분할에 이미 들어온 달의 행은 작업이 분할을 만들 때 봉인·추가 전용 보장을 지킨 채 새 분할로 옮긴다. 작업 `event_partition_maintain`이 석 달 앞까지 분할을 만들고 닫힌 달을 gzip JSONL과 서명 매니페스트로 내보내며(`event_partition_exported`), 보관은 `MINT_EVENT_RETENTION_DAYS`를 설정한 경우에만 작업 `event_retention`이 내보내기 파일을 다시 확인한 월 분할을 지운다(`event_partition_dropped`, 확인 실패 시 지우지 않고 경보 `export_failed`). `seal verify`는 지운 달의 봉인 구간을 내보내기 기록으로 설명한다. 사건 100만 행 복사에 약 30초가 걸리므로 적용 전에 백업한다(`docs/업그레이드.md`).
