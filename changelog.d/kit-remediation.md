- 관리형 단말 설치가 폐기·반려·미승인 서버를 스스로 정리한다(POL-D-02는 부분에서 조건부로 올라가고 POL-D-04의 한계가 줄어든다). 설치 보고 응답에 서버 이름 목록 `retired`가 실리고, 관리자 권한으로 도는 보고기(Linux 시스템 타이머, Windows SYSTEM 예약 작업)가 묶음이 쓴 Claude Code·Codex 관리형 설정 항목, 묶음 실행기가 기록한 프로세스(PID와 시작 시각이 맞을 때만), 묶음이 등록한 자동 시작 항목만 지우고 곧바로 `removed`로 다시 보고하며 항목마다 사건 `endpoint_remediated`가 남는다. 서버 실행기는 마지막 응답의 목록에 든 서버를 시작하지 않는다. 사용자 수준 설치와 사용자가 만든 항목은 그대로이고 경보만 남는다.
