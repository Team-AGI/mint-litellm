# 업그레이드

이전 판본에서 올릴 때 운영자가 확인할 일을 순서대로 적는다. 항목마다 한 줄이며, 해당하지 않는 항목은 건너뛴다.

## 올리는 순서

- [ ] 마이그레이션을 플러그인보다 먼저 적용한다. 새 열을 판정이 읽는다. `./mint.sh upgrade`가 이 순서로 한다.
- [ ] 정책 번들을 다시 활성화한다. 카탈로그가 바뀌어 새 규칙은 활성화해야 적용된다. `mint-litellm policy activate`
- [ ] LiteLLM 설정을 점검한다. 빠진 가드레일 모드와 필수 설정을 채운다. `mint-litellm init --fix-config config/litellm.config.yaml`
- [ ] 끝나면 점검한다. `mint-litellm check`, 이어서 `mint-litellm doctor`

## 승인이 영향을 받는 곳

- [ ] 서버 정의에 OAuth 범위(`scopes`)를 설정한 서버는 다시 승인한다. 이전 승인은 범위를 빈 값으로 기록해 넓어진 범위로 보이고 호출이 막힌다. 재검사 뒤 배포 계약을 다시 승인한다. `mint-litellm intake recheck <신청>`, `mint-litellm contract reapprove <서버> --intake <신청> --deployment-contract <후보>`
- [ ] 호출자 토큰을 업스트림에 그대로 전달하는 서버(`true_passthrough`·`oauth_delegate`)는 승인을 `--allow-token-forward`로 다시 만든다. 없으면 `MINT-TOKEN-FORWARD-FORBIDDEN`으로 막힌다. `mint-litellm approve ... --allow-token-forward`
- [ ] LiteLLM이 토큰을 받는 OAuth 서버(`auth_type: oauth2`)에 `upstream_resource`를 둔다. 없으면 점검을 통과하지 못한다. `mint-litellm init --fix-config config/litellm.config.yaml`이 `auto`(서버 주소)를 채운다.
- [ ] 버전이 고정되지 않은 패키지를 쓰는 로컬 서버는 `unpinned_acceptance` 증빙을 붙여야 승인된다. `mint-litellm evidence attach unpinned_acceptance <서버> --summary <사유>`
- [ ] 오래된 승인은 재확인을 받는다. 90일이 지난 승인은 재확인 요청과 경보가 열리고, 요청 뒤 14일 안에 확인이 없으면 보류되어 호출이 `APPROVAL_RECERT_REQUIRED`로 막힌다. 콘솔 승인 내역에서 「재확인」한다. 주기는 `MINT_RECERT_DAYS`·`MINT_RECERT_GRACE_DAYS`로 바꾼다.

## 동작이 바뀌는 곳

- [ ] 새로 쓰는 판정 사건 본문이 2판(`v: 2`)이 되고, 도구 목록의 「보임」 통과 반복은 하루(`MINT_LIST_DEDUP_SECONDS`) 동안 다시 기록하지 않는다. 기존 행은 그대로이며 본문 키를 직접 읽는 외부 도구는 빠진 키(빈 값·`stages`·`findings`·`mode` 등)를 없는 값으로 다뤄야 한다.
- [ ] 결과 상한 기본값이 생긴다. 승인에 `max_result_bytes`·`max_result_items`가 없으면 1 MiB·1000항목을 넘는 결과가 `MINT-OUTPUT-BLOCKED`로 바뀐다. 값을 바꾸려면 `MINT_DEFAULT_MAX_RESULT_BYTES`·`MINT_DEFAULT_MAX_RESULT_ITEMS`를 설정하고, 끄려면 0으로 둔다.
- [ ] 취약점 조회 주소를 확인한다. 기본은 `https://api.osv.dev`이며 사내 미러를 쓰려면 `MINT_VULN_FEED_URL`을 설정한다. 조회가 안 되면 `vuln_feed_unreachable` 경보만 열리고 호출은 막지 않는다. 폐쇄망에서는 이 경보가 계속 열려 있다.
- [ ] 호출량 급증 경보가 켜진다. 평소보다 3배 이상 늘고 5분에 50건 이상이면 열린다. 기준은 `MINT_SPIKE_FACTOR`·`MINT_SPIKE_MIN_CALLS`로 바꾼다.
